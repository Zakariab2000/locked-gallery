# The Locked Gallery

A co-op unsolved-cases web game for 2–4 players. Friends join by link — no install needed.

## How to play

1. Open the game and create a room — share the **room code** with your friends so they can join the same case.
2. Each player gets a role (Detective, Forensics, Profiler, Archivist) with secret clues.
3. Explore the crime scenes, examine the evidence, interrogate the suspects and solve the mini-puzzles.
4. Agree on **who** did it, **how**, and **where** — score 3/3 to close the case.

## Cases

- **Case 1 — The Locked Gallery:** an art heist in a locked gallery. 12 evidence items, 4 suspects.
- **Case 2 — Dinner for Five:** a murder at a dinner party.
